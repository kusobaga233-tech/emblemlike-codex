# 攻击确认闭环

延续治疗确认后的已批准路线。本轮仅统一攻击确认，不改角色资产/战斗伤害规则或第一章地图。

攻击模式悬停显示临时预测，无确认按钮；左键点击合法敌人锁定目标与预测，显示“确认攻击/取消”。重复点击敌人只更新锁定，不执行结算。锁定后指针离开角色或移至其他对象不替换/清除目标，左键点击另一合法敌人可换目标。预测显示敌人名与说明：剩余HP是普通命中预估，实际受命中/暴击影响。确认回调只对当前攻击模式和锁定目标有效，重新调用规则校验，成功后进入既有表现队列；失效目标拒绝并清除锁定。取消不消耗行动。移动未提交时，场内右键仍优先回退原格。

治疗的独立确认信号保留，公共取消按钮按当前模式清理；隐藏/清空面板要重置确认种类，避免攻击/治疗误路由。输入播放锁及busy守卫继续生效。已发生攻击不可右键回滚，待机提交约定不变。

不新增敌方AI/反击结算。现有反击字段仍属规则预测，本轮不声称已实现新的反击规则。
