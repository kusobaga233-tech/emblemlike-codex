# 悬停敌人属性（已确认方向）

本轮推进用户同意的悬停查看敌人属性，不扩展敌方威胁范围/AI/角色方案。采用与HUD右侧并排的只读卡片，不跟鼠标漂移，不用生成图片。

闲置/移动模式悬停存活敌人可看名称、兵种、可见生命/上限、攻击/伤害类型、防御/抗性、移动/射程、命中/暴击、已行动状态。查看不选中敌人、不调用规则命令、不消耗行动，也不取消移动预览或未提交移动。生命读表现节点已显示血量，行动播放时隐藏，避免泄露提前结算信息。

攻击/治疗目标模式优先原预测和确认，不显示属性卡覆盖它们。离开当前敌人、进入空地或友军、切换模式、重建战斗/行动播放、退出窗口会清理。快速换敌人后旧敌人的退出事件不得错误关闭新敌人卡片。UI忽略鼠标，不阻挡场内右键回退。卡片不支持锁定，范围仅为属性数值，不把射程当作移动后威胁。

1280x800及720x1280截图和实际鼠标悬停回归为验收证据；构建仍需独立EXE启动，不宣称完整人工通关/商业美术完成。
