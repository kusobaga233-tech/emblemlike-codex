# 第一章教学闭环（已确认方向）

日期：2026-11-05（Asia/Shanghai）
范围：第一章 `雾桥初阵` 的可玩教学闭环，不改角色美术、不改 AI 与战斗数值平衡。

## 目标

让第一次进入战斗的玩家在不查阅外部说明的情况下，依次完成并理解四件事：

1. 选择我方角色并移动；
2. 锁定并确认一次攻击；
3. 用艾利欧治疗受伤的相邻友军；
4. 积累星誓共鸣至 100%，由奥蕾莉亚与相邻且未行动的友军发动一次共鸣。

同时补齐战斗中持续可见的战术信息：目标（含进度与失败条件）、回合（含上限）和敌方威胁范围。

## 教学流程

- 新增 `TutorialFlow` 纯逻辑对象，四步固定顺序：移动 → 攻击 → 治疗 → 共鸣。
- 教学只观察已经结算的事件，不拦截、不代打、不修改任何规则状态；玩家仍可自由行动。
- 若玩家提前完成后续步骤，记录为已演示；轮到该步时直接推进，避免教学与实际操作冲突。
- 步骤完成判定：
  - 移动：我方单位的 `unit_moved`；
  - 攻击：我方单位 `unit_acted` 且 `action=attack`（命中或未命中均算）；
  - 治疗：我方单位 `unit_acted` 且 `action=support`；
  - 共鸣：`resonance_finished`。
- 教学面板显示步骤序号、标题、操作说明、提示和“跳过教学”。面板位于屏幕底部居中，鼠标事件除按钮外全部穿透，不遮挡左侧 HUD、右侧预测/属性面板与战场点击。
- 当前步骤在战场上有金色提示环；单位死亡、步骤推进、战斗结束或重建时清除。
- 跳过或完成后面板隐藏；战斗失败/胜利时不再显示教学。重开战斗从第一步开始。

## 目标与回合 HUD

- 回合显示上限：`回合：1 / 20`（无上限时保持 `回合：N`）。
- 目标显示进度：`胜利条件：击败雾桥队长（0/1）`；失败条件以第二行显示：`失败条件：奥蕾莉亚阵亡`。
- 目标/失败目标按实例 ID 或唯一定义 ID 解析显示名，保持与规则层一致。
- 所有信息只读，不改规则。

## 敌方威胁范围

- 新增纯函数 `ThreatRules`，按敌方存活单位、地形阻挡和其他存活单位计算：
  - 移动可达格（四向 BFS，水域与占位阻挡）；
  - 从任一可达格按该敌定义射程可攻击到的合法地块（排除水域等不可站立格）。
- `GreyboxBoard` 增加独立 `ThreatOverlay`：移动圈一层、攻击圈一层，颜色区分且低于移动/攻击选择层。
- HUD 增加“威胁范围”开关；默认关闭，切换后立即重算；单位移动、受伤、死亡、阶段变化与重建后刷新；敌方阶段与战斗结束后隐藏。
- 威胁范围仅为展示，不改变 AI、不预测命中/伤害、不替代悬停属性。

## 星誓共鸣操作

- HUD 在奥蕾莉亚被选中时显示“共鸣”按钮；共鸣值不足 100 时禁用并给出原因。
- 进入后先选相邻、存活且未行动的友军作为伙伴，再选射程内敌军；悬停显示固定伤害预览，点击锁定，确认后调用既有 `use_resonance_selected` 规则命令。
- 取消、右键、切换选择、行动播放都清理预览，不扣共鸣、不消耗行动。
- 计算固定伤害时复用规则层同一函数，避免 UI 与结算公式漂移。
